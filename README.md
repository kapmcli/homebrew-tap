# homebrew-tap

Homebrew tap for [kapm](https://github.com/kapmcli/kapm) — Kiro Agent Package Manager.

## Installation

```bash
export HOMEBREW_GITHUB_API_TOKEN=ghp_xxxxxxxxxxxx  # GitHub PAT with repo scope
brew tap kapmcli/tap
brew install kapmcli/tap/kapm
```

## Requirements

Since this is a private tap, you need a GitHub Personal Access Token with `repo` scope set as `HOMEBREW_GITHUB_API_TOKEN`.
